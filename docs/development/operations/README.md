# Operations

Procedures for running and recovering the template and its workflows.

- Runbooks: `runbook-<task>.md`: `runbook-create-template-repository.md` (done 26 October 2026), `runbook-promote-to-public.md` (W-11), `runbook-move-git-local-to-platform.md` (W-12), `runbook-instantiate-library.md` (W-01 and the V-06 timing sheet), `runbook-revision-writer-recovery.md`, `runbook-remove-leaked-content.md`.
- Rollback plans: `rollback-<change>.md`, written before a risky change ships.
- Postmortems: `postmortem-YYYY-MM-DD-<slug>.md`, blameless, with actions linked to RFCs, ADRs or requirements.
