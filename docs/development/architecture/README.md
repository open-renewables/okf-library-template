# Architecture

How the template is built.

- `OKF Library Template - Software Design Document.md` (the SDD) and `OKF library technology stack options.md` keep their exact file names.
- Overview notes, diagrams and the data model are added as lowercase hyphenated files, for example `data-model.md`; diagram sources (Mermaid, DOT, SVG) sit beside the page that uses them.
- Architecture documents change in the same pull request as the code they describe.
