# Requirements

What the template must do. Owned by people: agents may draft, but only the owner creates a requirement's file in its final place or changes its status.

- `OKF Library Template - Software Requirements Spec.md` is the requirements baseline (FR1.1 to FR8.5, NFR1 to NFR7) and keeps its exact file name.
- Work after the baseline is specified as one file per feature: `<feature>-prd.md` (lowercase, hyphenated), or `<feature>-brief.md` and `<feature>-stories.md` where a full PRD is not needed.
- Every file starts with a status line: `Status: Draft|Accepted|Done|Superseded`. A superseded file names its replacement.
- A PRD cites the SRS requirement IDs it adds to or changes.
