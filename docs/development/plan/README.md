# Plan

The current piece of work only. Exactly one feature is in progress at a time.

| File | Holds |
| --- | --- |
| `SPEC.md` | What will be built: links the accepted requirement and references `../conventions.md`, `../constraints.md` and `../testing/` instead of restating them |
| `plan.md` | How: the sequence of steps and their checks |
| `todo.md` | A checklist of the steps, ticked as they are done |

When the work ships, the three files move together to `archive/YYYY-MM-<feature>/` and the requirement's status is set to `Done`. The folder is then empty apart from this README.
