# Requests for change

Proposals for design changes that need discussion before a decision.

- **Until template v1.0.0:** RFCs are files in this folder (owner decision, 25 October 2026).
- **From v1.0.0:** RFCs move to GitHub issues labelled `rfc`. This README then becomes a pointer to that label and lists the range of RFC files written before the move; those files stay as read-only history, and ADRs made after the move link the issue.
- **File format:** one file per RFC, `RFC-NNN-title.md`, numbered in sequence from RFC-001, lowercase hyphenated title. Each starts with `Status: Draft|Accepted|Rejected|Withdrawn` and lists the ADRs it produced. Numbers are never reused.
